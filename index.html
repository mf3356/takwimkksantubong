Export & Import Data

📤
Export Data Dashboard
Muat turun semua data (program, jawatankuasa, pengumuman, laporan) sebagai fail .json untuk dikongsi dengan Ketua Unit lain.

💡 Fail JSON boleh dihantar melalui WhatsApp, e-mel, atau Google Drive kepada Ketua Unit lain untuk mereka Import ke dashboard mereka.

📥
Import Data Dashboard
Muatkan fail .json yang diterima daripada Penyelaras Takwim untuk melihat data terkini.

⚠️ Import akan menggantikan semua data sedia ada dalam dashboard ini. Pastikan anda mengeksport data lama terlebih dahulu jika perlu.
